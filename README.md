# LgpdRetention

Filament plugin for laravel-lgpd-retention: preview and run LGPD data retention, re-apply erasure after a backup restore, and browse the tombstones of anonymized columns.

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/filament-lgpd-retention
```
